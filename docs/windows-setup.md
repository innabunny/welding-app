# Запуск портала на чистом ноутбуке с Windows

Всё по порядку, от пустой машины до узла на кабеле. Команды — в PowerShell.

## 1. Поставить программы

1. **Git for Windows** — https://git-scm.com/download/win, установка с настройками по умолчанию.
2. **Docker Desktop** — https://www.docker.com/products/docker-desktop/. При установке оставить «Use WSL 2». После установки перезагрузить компьютер.
3. Запустить Docker Desktop и дождаться внизу слева «Engine running». В настройках (Settings → General) включить «Start Docker Desktop when you sign in» — тогда портал поднимется сам после перезагрузки.
4. Проверить в PowerShell:

   ```powershell
   git --version
   docker compose version
   ```

Памяти ноутбуку нужно от 8 ГБ.

## 2. Скачать проект

```powershell
cd C:\
git clone https://github.com/innabunny/welding-app.git
cd C:\welding-app
```

Если репозиторий закрытый, Git откроет окно входа в GitHub.

## 3. Настройки машины

```powershell
copy .env.example .env
notepad .env
```

Пока ничего не менять: `POLL_NODES=1` уже включает опрос узлов, `PORTAL_HOST` заполняется позже, если портал понадобится с других устройств (раздел 9). Сохранить и закрыть.

## 4. Поднять контейнеры

```powershell
docker compose up -d --build
```

Первый раз — 5–15 минут, скачивается всё нужное. Проверить, что все семь контейнеров работают:

```powershell
docker compose ps
```

У каждого в колонке STATUS должно быть `Up`.

## 5. База: миграции, справочники, администратор

Миграции применяются сами при старте бэкенда. Повторить вручную не вредно:

```powershell
docker compose exec backend python manage.py migrate
```

Справочники: оборудование, способы сварки, материалы, цеха, график смен:

```powershell
docker compose exec backend python manage.py loaddata fixtures/seed.json
```

Администратор портала. Спросит пароль два раза, на экране он не виден:

```powershell
docker compose exec backend python manage.py create_admin
```

Логин — `admin`. Свой логин можно передать: `create_admin ivanova`.

## 6. Открыть портал

```
http://localhost:5173
```

Войти под администратором из шага 5.

**Демонстрационные данные — по желанию.** Они нужны, только чтобы посмотреть экраны на наполненной базе:

```powershell
docker compose exec backend python manage.py seed_demo
```

Команда заводит демо-учётки с простыми паролями. Учётке `admin` она ставит пароль `admin`. Если администратор из шага 5 тоже называется `admin`, его пароль перезапишется — тогда повторите `create_admin`.

## 7. Заполнить справочники в портале

- **Оборудование.** У аппарата, к которому подключён узел, указать узел телеметрии: имя (например, `node-01`) и адрес (например, `192.168.1.50`). Опрос подхватит его сам в течение 30 секунд, перезапускать ничего не нужно.
- **Аттестация сварщиков.** Каждому сварщику вписать номер его RFID-карты, как напечатан на карте. Без номера сеанс откроется без сварщика.

## 8. Сеть и узел

1. Воткнуть кабель от узла (или от коммутатора, к которому он подключён) в ноутбук.
2. Задать проводному адаптеру адрес из сети узла. `Win + R` → `ncpa.cpl` → правой кнопкой по Ethernet → Свойства → «IP версии 4 (TCP/IPv4)» → Свойства:
   - «Использовать следующий IP-адрес»: `192.168.1.10` (любой свободный в сети узла);
   - маска: `255.255.255.0`;
   - шлюз и DNS — пусто, если интернет идёт по Wi-Fi.
3. Если Windows спросит про тип сети — «Частная».
4. Выключить VPN, если он есть.
5. Проверить узел с ноутбука. Именно `curl.exe`: просто `curl` в PowerShell — другая команда.

   ```powershell
   curl.exe http://192.168.1.50/api/state
   ```

   В ответ — строка с `"a":`, `"v":`, `"arc":`.

6. Проверить, что узел виден из контейнера приёмника:

   ```powershell
   docker compose exec collector python -c "import urllib.request; print(urllib.request.urlopen('http://192.168.1.50/api/state', timeout=2).read())"
   ```

7. Посмотреть журнал приёмника:

   ```powershell
   docker compose logs -f collector
   ```

   Должно быть `опрос узла node-01: http://192.168.1.50/api/state`. Сварщик прикладывает карту — `сеанс ... начат`. Выход из журнала — `Ctrl + C`.

Сеанс закрывается, когда карту убрали или 10 минут не было дуги. Порог — `POLL_SESSION_IDLE_SECONDS` в `.env`, после правки: `docker compose up -d collector`.

## 9. Портал с других устройств — по желанию

1. В `.env` вписать адрес ноутбука: `PORTAL_HOST=192.168.1.10`. Применить:

   ```powershell
   docker compose up -d backend
   ```

2. Разрешить входящие на порт 5173 (PowerShell **от администратора**):

   ```powershell
   New-NetFirewallRule -DisplayName "Портал сварки 5173" -Direction Inbound -Protocol TCP -LocalPort 5173 -Action Allow -Profile Private
   ```

3. С другого устройства: `http://192.168.1.10:5173`.

Наружу открыт только портал. База, Redis, ClickHouse, MQTT и прямой порт бэкенда доступны лишь с самого ноутбука.

## Проверка без аппарата

Имитатор узла работает внутри контейнера приёмника. В справочнике у аппарата указать адрес узла `127.0.0.1` и запустить:

```powershell
docker compose exec -d collector python node_stub.py
```

Сценарий около четырёх минут: карта, дуга полторы минуты, пауза, дуга с просадкой, простой, карту убрали. После проверки вернуть в справочнике настоящий адрес узла.

## Обновить проект

```powershell
cd C:\welding-app
git pull
docker compose up -d --build
```

## Если что-то не так

| Что видно | Что сделать |
|---|---|
| `docker` не найден или «engine not running» | Запустить Docker Desktop, дождаться «Engine running» |
| Контейнер не в `Up` | `docker compose logs <имя>`, например `docker compose logs backend` |
| Порт 5173 занят | Закрыть программу на этом порту или поменять левую часть в `docker-compose.yml`: `"5174:5173"` |
| Не входит в портал | Повторить `create_admin` — пароль сменится |
| С другого устройства ошибка 400 | Неверный `PORTAL_HOST` в `.env`; после правки — `docker compose up -d backend` |
| `curl.exe` до узла не отвечает | Кабель, питание узла, адрес адаптера в той же подсети, выключен ли VPN |
| С ноутбука узел отвечает, из контейнера нет | Выключить VPN, перезапустить Docker Desktop |
| В журнале «узлов с адресом в справочнике нет» | Вписать адрес узла у аппарата (шаг 7) |
| Сеанс без сварщика | Номер карты не вписан у сварщика (шаг 7) |
